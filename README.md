A GTA 6 meme about the 13-year wait for Vice City: an exhausted gamer slumps beside a tower of calendars in Leonida while the make.fun ghost agent has already been paid. The meme picture (composed in this session by `make_meme.py` from an illustrated Leonida scene and make.fun's official press-kit ghost mark) is posted on X, `POST.txt` holds the post's exact text, `POST.json` hands in the post's address, and `main.ts` copies `POST.json` to the grader's output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
